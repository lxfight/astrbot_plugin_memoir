# 多层转发消息

Memoir 会在后台展开新收到的转发，将文本和受支持媒体的描述保存为可检索的引用资料。无需额外开启转发开关，沿用私聊、群聊和会话记忆开关。

这项功能服务于后续记忆与召回。私聊仍在回复后捕获；后台解析不会让当前这次回复立即获得完整转发内容，也不会主动唤醒群聊机器人。升级前的转发没有保存引用，无法追补。

## 适配器支持范围

| 输入 | 处理方式 | 限制 |
| --- | --- | --- |
| AstrBot `Node` / `Nodes` | 递归展开内嵌内容，保留节点路径、署名和原时间 | 依赖适配器实际交付的组件 |
| OneBot / `aiocqhttp`，如 NapCat | 使用原适配器实例的 `get_forward_msg` 拉取 `Forward.id`，继续展开嵌套引用 | 兼容 `message_id` / `id`、字符串 / 数字参数，以及常见响应包装；权限不足、过期、超时可能导致部分解析 |
| Satori | 从原始 `message.content` 读取内嵌转发结构，保留作者边界 | 只有引用 ID、没有内嵌正文时显示暂不支持，不调用 OneBot API |
| Telegram | 保存已交付的转发正文、媒体及 `forward_origin` 中可见署名 | 不还原平台未交付的历史转发链 |
| Discord | 保存已交付的正文、消息快照及快照中的图片、音频 | 不反向抓取隐藏的原始消息；其他附件保留占位符 |
| 飞书 `merge_forward`、其他适配器的引用 | 保留适配器已提供的预览或内嵌通用组件 | 没有通用的跨平台远程展开接口；缺失部分明确标注 |
| QQ 合并转发 JSON 卡片 | 保存可见预览文字 | 预览不是全文，不从任意卡片字段推测拉取地址 |

以上分支通过适配器形状的离线测试验证；实际可读内容仍由平台、适配器版本及账号权限决定。插件不会修改 AstrBot 核心。

## 来源与记忆隔离

- 原始转发事件保留实际发送者；引用分块另外记录父事件、节点路径、声明的原作者和原时间。署名和 ID 均标为未验证，不当作群成员身份。
- 转发引用与普通对话分批巩固。引用只产生带来源标记的可检索资料，不覆盖已有个人记忆，不生成个人洞察，不进入常驻认知，不参与群聊到私聊的自我陈述桥接。
- 一些适配器会把转发正文混入 `message_str`。为避免误认，**包含转发的整条入站消息，包括外层附言，均按引用资料处理**。需要记住自己的新事实时，请单独发一条普通消息。
- 召回时继续标明“转发引用、不是用户自述”，引用里的指令也作为资料处理。模型提炼仍可能有误，可在 WebUI 展开来源核对。

## 边界与成本

| 项目 | 限制 |
| --- | --- |
| 嵌套层数 | 最多 5 层消息节点 |
| 内容规模 | 最多 100 个可读内容段、600 个结构段；正文最多 20,000 字符，另有有限的来源标注和媒体摘要 |
| 存储分块 | 按内容段保存；长段每 1,500 字符拆分，尾段可参与原文检索 |
| 远程请求 | 每条转发最多 10 次动作调用，兼容参数重试也计入 |
| 展开超时 | 单次拉取 5 秒，整个展开阶段 30 秒；已获取正文保留 |
| 处理队列 | 与普通媒体共用 32 个活跃任务、2 个工作者 |
| 媒体 | 整条转发共享最多 4 个图片/音频；引用最多 4 MiB；实际文件单个 10 MiB、合计 20 MiB |
| 媒体处理 | 在展开后单独进行，最多 110 秒；图片、音频分别沿用全局所选模型及能力检查 |

纯文本展开不调用模型。图片、音频按提供商合并描述：同一提供商额外调用一次，分别选择不同提供商时最多两次；定期引用巩固也会产生模型费用。调用与重试可在「用量统计」查看。部分能力不支持时保留占位符，并显示部分解析；视频仍保留占位符。

重复或循环的远程引用只获取一次，重复处标记为省略；超过预算或个别节点失败不会伪装成完整解析。排队及处理中的事件暂不参与巩固。巩固触发数量按原始事件去重，不把一条长转发的分块数算成多条消息。

## 查看、恢复与删除

在「原文对话」向上滚动查看历史及解析状态，点击转发气泡的「查看聊天记录」（或「⋯」菜单中的「展开转发层级」）核对路径和署名、复制全文或删除分块。提炼后的记忆卡片也标明“转发引用 · 非个人画像”。

在「处理任务」查看错误并重试可恢复任务。网络或适配器实例暂时不可用时可以重试；只有预览、结构/大小超限或模型能力不支持时，请调整输入或模型后重新发送。重试沿用原来的事件与分块 ID，不重复插入已有分块。

队列暂存必要的文本、媒体引用及适配器实例 ID，不保存 bot 对象或凭据。成功或确定不可重试后清除队列输入；可重试失败最多保留 30 天。插件重启会恢复未完成任务，并重新寻找相同实例，避免误用另一个机器人账号。

删除原始事件会连同分块和任务一起删除；单独删除分块也会取消该事件的后续解析任务，防止重试将它写回。删除来源不会自动删除已经提炼的记忆，来源面板会提示缺失；需要彻底删除时使用「清空会话」。关闭或清空会话会使正在处理的旧结果失效。

原文保留期沿用会话设置；容量上限按 500 条原始事件计，分块随父事件清理。群聊忽略规则也检查展开后的正文，命中时删除整个原始事件及分块；若关键词来自媒体描述，该媒体此时已发送给模型。
